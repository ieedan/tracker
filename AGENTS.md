This project is a project to test the capabilities of implementjs and to find and fix bugs.

## Finding bugs, missing features, and papercuts in implementjs

There are 3 categories of things we are trying to find:
1. Bugs in implementjs (or it's libraries)
2. Papercuts given from implementjs - Things that were not obvious or broken that caused friction
3. Features that are missing from implementjs or it's libraries that would have been useful

When you find one of these please create an issue the implementjs workspace (follow the steps for creating an issue below) (after checking if it already exists) using the tracker MCP. Once you do that tag your workaround or solution with the issue number (ENG-XXX).

### Creating issues in implementjs using the tracker MCP

Use the tracker MCP to create an issue in the implementjs workspace.
- Leave it as backlog
- Label it with "Auto Generated"
- Choose a label for your issue depending on the category of issue (either "Bug", "Papercut", "Feature") feel free to also tag the effected package
